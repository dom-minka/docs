## The Problem

Documentation is a core part of the developer experience. Yet, most companies struggle to create and maintain good documentation. Why? Because the current documentation process is painful.

<CardGroup cols={2}>
  <Card title="Hard to Set Up" icon="circle-1">
    Most developer tools for documentation require a complex setup process, with knowledge of various frameworks and deployment processes.
  </Card>
  <Card title="Difficult to Maintain" icon="circle-2">
    Documentation is often treated as a secondary task, leading to outdated information and frustrated users.
  </Card>
  <Card title="Poor User Experience" icon="circle-3">
    Many documentation sites are difficult to navigate, lack search functionality, and don't provide a good reading experience.
  </Card>
  <Card title="Limited Collaboration" icon="circle-4">
    Traditional documentation processes make it hard for teams to collaborate and keep content up-to-date.
  </Card>
</CardGroup>

## Our Solution

Mintlify provides a complete platform for creating, maintaining, and hosting beautiful documentation sites. We've built a system that makes it easy to create documentation that developers love.

<Card title="Mintlify Writer" icon="pen-to-square" iconType="duotone">
  Mintlify Writer helps you create documentation faster with AI. It can generate documentation from your code, or help you write documentation from scratch.
</Card>

<CardGroup cols={2}>
  <Card title="Mintlify Publisher" icon="upload" iconType="duotone">
    Mintlify Publisher allows you to publish your documentation with a single command. No need to worry about deployment or hosting.
  </Card>
  <Card title="Mintlify Reader" icon="book-open-reader" iconType="duotone">
    Mintlify Reader provides a beautiful reading experience for your documentation, with features like search, dark mode, and mobile responsiveness.
  </Card>
</CardGroup>
